# Ảnh phản hồi học viên

Chép ảnh chụp tin nhắn Zalo (PNG/JPG, **đã che tên và ảnh đại diện**) vào thư mục này.

- Website tự nén sang WebP, tự xếp lên "bảng ghim" và tự đếm số ảnh để hiện "[N]+ phản hồi".
- Ảnh hiện theo thứ tự tên file. Muốn ảnh nào lên đầu, đặt tên bắt đầu bằng số nhỏ (vd `01-anh-hung.png`).
- Khi thư mục chưa có ảnh nào, trang dùng ảnh mẫu và ẩn con số.
